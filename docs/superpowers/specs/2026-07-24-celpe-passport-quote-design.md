# CELPE-BRAS — блок «паспорт + цитата»

**Дата:** 2026-07-24
**Секция:** `landing/components/sections/CelpeBras.tsx`
**Статус:** дизайн одобрен, готов к плану реализации

## Цель

Добавить в секцию CELPE-BRAS вводный блок «фото паспорта + цитата» сразу под
заголовком. Блок вводит тему секции визуально (обложка бразильского паспорта) и
одной фразой (официальный экзамен → путь к гражданству).

## Порядок секции (после изменения)

```
1. Heading  (AdaptiveText h2)
2. Passport + Quote  ← НОВЫЙ блок
3. Features + отзыв  (существующая сетка карточек; цитата-отзыв из Notion не трогается)
4. Hint + CTA
```

Новый блок вставляется в существующий `flex-col gap-[64px]` контейнер секции —
между заголовком и сеткой фич. Существующая цитата-отзыв (`data.quote`,
«Мы прошли этот путь сами…») остаётся в 3-м ряду сетки без изменений.

## Ассет

- Источник: `Assets/Brazil passport.png` — 550×776 px, портрет, AR 0.7088, ~700 КБ.
- Назначение: `landing/public/PNG/celpe/brazil-passport.png` (новая подпапка
  `celpe/`, по образцу `about/`, `comparison/`).

  отдаёт webp/avif по запросу.
- Рендер строго через `next/image` (правило проекта — никаких `<img>` для растра).

  (`FeatureCard`/`CelpeBrasStack` = `rounded-[44px]`). Обёртка `next/image` —
  `overflow-hidden` для клиппинга. Мягкая drop-shadow, чтобы приподнять над
  фоном-коллажем. Дополнительного скругления сверх 44px нет.

## Раскладка

### Широкие экраны (≥1024px, `lg`) — 2 колонки В ТОН сетке фич (паспорт = карточка, цитата = карточка)

Реализовано ОДНИМ контейнером (не два блока): mobile — `flex flex-col`, desktop —
`lg:grid lg:grid-cols-2 lg:gap-[20px]` (тот же gap, что в рядах карточек фич, → колонки
совпадают по ширине с карточкой). `order`-своп меняет визуальный порядок без дублирования
DOM/картинки.

```
┌──────────────────────────────────────────────────────────────┐
│ ┌──────────────────────┐ 20px ┌──────────────────────────────┐│
│ │      паспорт         │◄────►│    «Официальный экзамен…»     ││ = ширина карточки
│ │  = ширина карточки   │      │   (lg:px-32, кегль ↓, центр)  ││ (правая колонка)
│ │  (заполняет колонку) │      └──────────────────────────────┘│
│ └──────────────────────┘  ← высота по AR (портрет → высокий)  │
└──────────────────────────────────────────────────────────────┘
   grid-cols-2 items-center → цитата V-центрируется относительно высоты паспорта
```

- Контейнер: `lg:grid lg:grid-cols-2 lg:gap-[20px] lg:items-center`.
- Паспорт: `lg:w-full` — заполняет левую колонку (= ширина карточки); высота по AR
  550/776 (портрет → на широких экранах становится ВЫСОКИМ, ~ширина×1.41);
  `rounded-[44px] overflow-hidden`, drop-shadow, `object-cover` (бокс aspect-точный →
  без кропа).
- Цитата: правая колонка (= ширина карточки); `<AdaptiveText as="p">` c
  `text-center mx-auto`, внутренний отступ `lg:px-[32px]` (в тон карточкам). `items-center`
  родителя даёт вертикальный центр относительно высоты паспорта.
- Шрифт цитаты (уменьшен ~÷1.5): `clamp(15px, 1.3vw, 23px)`, line-height 1.35.
- Letter-spacing (общий для всех ширин): инверсный `clamp(0.3px, calc(2.8px - 0.13vw), 2.4px)`
  — чем уже вьюпорт, тем шире межбуквенное расстояние (~2.4px на мобилке → ~0.4px на 1920).

> **Следствие:** при паспорте = ширина карточки его высота = ширина×1.41 (портрет),
> поэтому на десктопе паспорт крупный (~1000px при карточке ~710px), а секция высокая
> (~2052px на 1440). Открытый рычаг при необходимости — кап высоты паспорта (`lg:max-h`)
> или возврат к более узкой колонке.

### Узкие экраны (<1024px) — цитата сверху, паспорт снизу

```
┌────────────────────────┐
│   «Официальный экзамен, │  цитата первой, text-center
│   …гражданству.»        │
│       ┌─────────┐       │
│       │ паспорт │       │  паспорт ниже, по центру
│       └─────────┘       │
└────────────────────────┘
   flex-col items-center gap-[40px]
```

- Контейнер: тот же (`flex flex-col items-center gap-[40px]` до `lg`); `order`-своп
  ставит цитату первой.
- Цитата: `<AdaptiveText as="p">`, `text-center`, шрифт `clamp(17px, 4vw, 26px)`,
  горизонтальные отступы (`px-[16px]`), чтобы не липла к краям.
- Паспорт: ширина `clamp(200px, 62vw, 300px)` (высота авто), по центру,
  `rounded-[44px]`, та же тень.

## Правила адаптации двух объектов по всему диапазону

| Ширина | Раскладка | Паспорт (ширина → высота) | Цитата |
|---|---|---|---|
| ≥1024 (десктоп) | 2 колонки (= карточки) | = ширина колонки `≈(W−20)/2`; высота `×1.41` (портрет → высокий) | `1.3vw` (пол 15 / кап 23px); V-центр; `lg:px-32` |
| 484–1023 | стек, центр | ширина 300px (кап) под цитатой | 26px кап; по центру |
| 322–484 | стек, центр | ширина `62vw` (200→300px) | масштаб `4vw` |
| <322 | стек, центр | ширина 200px (пол) | ~17px мин (пол) |

Letter-spacing цитаты — инверсный `clamp(0.3px, calc(2.8px - 0.13vw), 2.4px)` по всему
диапазону: узкий экран → шире разрядка (~2.4px), широкий → плотнее (~0.4px на 1920).

Паспорт: на `lg+` `w-full` (= ширина колонки/карточки), высота по AR 550/776;
на узких — `clamp(200px, 62vw, 300px)` по ширине, высота по AR. Границы мобильных
строк — точки, где клэмп упирается в пол/кап; между
ними масштаб плавный.

Единственная дискретная точка переключения ряд↔стек — `lg` (1024px), как и вся
остальная секция. Внутри диапазонов масштаб плавный (`clamp`/`vw`).

## Адаптивный текст и фон

- Цитата рендерится через `<AdaptiveText as="p">` — дуотон ink↔cream по
  фону-коллажу, как заголовок и остальной текст секции.
- Паспорт — непрозрачный PNG, без адаптива; мягкая тень для отрыва от фона.

## Локализация (ru / en / pt — жёсткое требование проекта)

Цитата паспорта хранится **не в Notion** (в русле отказа от Notion), а как
локализованная константа (`ru`/`en`/`pt`). Существующий `data.quote` (отзыв)
пока остаётся из Notion — смешение источников допустимо на время перехода.

- **ru:** «Официальный экзамен, подтверждающий знание языка и открывающий путь к
  бразильскому гражданству.»
- **en:** "The official exam that certifies your language proficiency and opens
  the path to Brazilian citizenship."
- **pt:** "O exame oficial que comprova o conhecimento do idioma e abre o caminho
  para a cidadania brasileira."

Способ прокидывания константы (в `CelpeBrasData` через `lib/notion.ts` из локального
словаря vs. отдельный локализованный map в компоненте) уточняется на этапе плана;
требование — значение приходит по локали, без Notion.
