Анимация волн — как двигаются полосы?

Три подхода. Все демо — живые. Вариант C: наведи мышь чтобы увидеть эффект скролла.

Статично — полосы смещаются только при скролле страницы

A — Scroll-driven

Волны смещаются горизонтально пропорционально прокрутке. Каждый слой — свой коэффициент скорости. Использует useScrollAnimation. Эффект параллакса.

Автоматический дрейф — смотри как слои плывут в разных темпах

B — CSS Auto-animation

Волны непрерывно дрейфуют горизонтально через CSS @keyframes. Не зависит от скролла. Работает сразу как секция появляется в экране. Нет RAF.

Наведи мышь → ускорение (имитирует скролл)

C — Гибрид

Базовый CSS-дрейф всегда активен + скоростной множитель от useScrollAnimation. При быстром скролле волны ускоряются, при остановке — замедляются. Самый живой эффект.
