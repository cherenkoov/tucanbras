Волны с контр-анимацией по скроллу

Чёрные ← влево, белые → вправо. Тяни слайдер — симулирует скролл страницы.

↑ Скролл ↓ 0 px
Чёрные полосы (ink) translateX(-progress × speed)
движутся влево при скролле вниз
Белые полосы (cream) translateX(+progress × speed)
движутся вправо при скролле вниз
Реализация useScrollAnimation hook → RAF → прямое изменение style.transform на ref.
Idle stop после 60 кадров без движения. prefers-reduced-motion → статика.
